Units of measurement
The Shire uses the SI (International System of Units - Wikipedia) system for all units of measurement, except for temperature. Here Degree Celsius is used. 

 PDF The linked OIML documentation also supports the use of SI units

Base units
The base units of the units used in the Shire are listed in the table below.


s	second	time	
m	metre	length	
kg	kilogram	mass	
A	ampere	electric current	
°C	degrees Celsius	thermodynamic temperature	also  "degC" may be used
mol	mole	amount of substance	
cd	candela	luminous intensity	
Dimensionless units are the following:

rad	radian	plane angle	
%	percent	ratio	also "Percent" may be used
All other units are derived from those units.

ROS implementation
All units of measurement are defined in ROS messages. This allows for a clear strongly typed interface on which the system can be build. Base units are defined plainly, derived units are defined with a reference to thier definition. All units use float64 as ther data type (exceptions may be defined later) Examples are:

This provides the following benefits:

Increased readability/clarity: No more comments needed within the .msg file to describe that, e.g. the "float32 cpu_usage" value has a range of 0.0 -100.0, because that is documented in the Percent.msg definition.
No precision loss and interface consistency: If all ros interfaces use Meters.msg, all "meters" will always be of type float64 (because it was defined like that in Meters.msg) and never suffer from loss of precision due to inconsistencies in ros message definitions.
 
Time units
Time measurements are stored in ROS msg/Time Message . 

Communication 
All ROS messages in the Shire use the defined unit system. Unitless messages are not allowed, as well as no messages with arbitrary units.

Measurements of speed
All measurements of speed are communicated as meters per second as far into the chain as possible. A central library provided the conversion functionality to convert units of speed
